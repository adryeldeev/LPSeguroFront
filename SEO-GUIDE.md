# 🎯 Guia de SEO - QU4TROS Seguros

## ✅ O que foi implementado

### 1. Meta Tags Essenciais
- **Title otimizado**: Inclui palavra-chave principal e valor diferencial
- **Description**: 155-160 caracteres com call-to-action
- **Keywords**: Palavras-chave estratégicas do nicho de seguros

### 2. Open Graph (Facebook/LinkedIn)
- Otimização para compartilhamento em redes sociais
- Imagem destacada customizada
- Título e descrição específicos

### 3. Twitter Cards
- Cartões otimizados para Twitter
- Imagens e textos personalizados

### 4. Schema.org (Dados Estruturados)
- **Organization**: Informações da empresa
- **Service**: Descrição dos serviços
- **FAQPage**: Perguntas frequentes estruturadas

### 5. Arquivos Complementares
- **robots.txt**: Instruções para crawlers
- **sitemap.xml**: Mapa do site para indexação
- **.htaccess**: Otimizações de servidor

- [ ] Registrar no Google Search Console

- [ ] Configurar Google Analytics 4
- [ ] Criar perfil no Google Meu Negócio

  - `/public/og-image.jpg`

- [ ] Adicionar favicon
  - `/public/favicon.png` (32x32)

- [ ] Testar velocidade (PageSpeed Insights)
